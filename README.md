# mir-betona33.ru — рабочий проект

Внутри — подпапки по направлениям (сайт + ещё 3-4 проекта).

## Структура
- `seo/` — SEO: `seo/reports/` (отчёты с датами), `seo/data/` (сырые данные API)
- `design/` — дизайны (макеты, прототипы)

Новые направления добавляем папками по мере появления.

## Инструменты
- MCP `yandex-marketing-mcp`: 155 тулзов (`yd_webmaster_*`, `yd_metrika_*`, `yd_direct_*`, `yd_wordstat_*`)
- Яндекс-аккаунт: Вебмастер user_id 80115328; токен в ~/.yandex-marketing-mcp/config.json
- Режим read-only; Wordstat требует сервисный аккаунт Yandex Cloud
